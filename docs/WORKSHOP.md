기획 · 디자인 · 개발이 섞인 3~6명. 각자 노트북에 이 저장소와 AI 도구가 준비된 상태에서 시작합니다. 목표는 **HDS 컴포넌트만으로 끝까지 조립되는지**를 모두가 눈으로 확인하는 것입니다.

## 진행 (30분)

| 시간 | 할 일 |
| --- | --- |
| 0~5분 | 참조 화면을 같이 본다. 「이 화면이 HDS 컴포넌트 30개 + 커스텀 1개로 돼 있다」를 보여준다 (`npm run hds:report`) |
| 5~20분 | 과제 카드 하나를 골라 각자 AI 도구로 만든다. 브랜치 이름 `exp/<이름>-<과제>` |

| 25~30분 | 돌아가며 1분씩 보여준다. 운영자는 **커스텀 마커 목록**을 한 화면에 모은다 |

## 과제 카드

**A. 탑승자 연락처 단계 추가**
> package-payment 화면에서 결제수단 앞에 「예약자 연락처」 단계를 넣어. 이름 · 휴대폰 · 이메일 TextInput, 휴대폰은 숫자만, 이메일 형식 오류 helper text. src/mock/booking의 contact를 초기값으로.

**B. 쿠폰 선택을 바텀시트로**
> 쿠폰 목록을 본문에서 빼고 「쿠폰 선택」 ListCell을 누르면 BottomSheet가 열려 고르게 해. 고른 쿠폰 이름이 ListCell trailing에 보이게. 쿠폰이 없으면 바텀시트 안에 EmptyState.

**C. 결제 실패 · 재시도**
> 결제하기를 누르면 2초 로딩 뒤 30% 확률로 실패해. 실패하면 AlertDialog(제목 · 설명 · 다시 시도 · 닫기)와 Toast negative. 성공하면 「예약이 완료됐어요」 화면으로 (EmptyState를 쓰지 말고 간단한 완료 화면).
